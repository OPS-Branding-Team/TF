# LAST PICK · 모바일 워크숍

10명의 참가자가 자신의 휴대폰으로 로그인하고 관리자 태블릿에서 팀 추첨, 초능력 발동, 점수 집계, 최종 공개를 운영하는 모바일 웹/PWA입니다.

## 빠른 실행

Node.js 22 이상에서 `npm start` → `http://localhost:3000`.

관리자: 첫 로그인 화면 **관리자 최초 접속** → 기본 관리자 PIN `0311`. 관리자 모드에서는 전체 참가자별 **개인 로그인 코드**를 확인할 수 있습니다. 개인 코드는 시작 시 자동 생성됩니다. 참가자는 이름과 발급된 개인 코드를 입력해 로그인합니다.

관리자는 **초능력 뽑기** 메뉴에서 먼저 `초능력 추첨 오픈`을 누릅니다. 각 참가자가 자기 모바일에서 카드를 뽑으면 서버 DB에 중복 없이 저장됩니다.

볼링 관리 화면에서는 `랜덤 팀 뽑기`를 누르면 10명 중 무작위 5:5 편성됩니다. PC방 관리 화면에서는 같은 버튼으로 **심승선 A팀장 / 최우재 B팀장** 고정, 나머지 8명 무작위 4:4 배정됩니다. 관리자 실행 시 발표 이벤트가 DB에 저장되어 접속된 모바일에 약 1~2초 이내 팝업으로 표시됩니다. 해당 이벤트는 관리자 태블릿에 모두 모이지 않아도 각자 확인할 수 있습니다.

관리자 `점수 입력`에서는 점수 수정과 기록 확인, `시상식`에서 최종 점수 공개 스위치를 사용할 수 있습니다. 비공개 중에는 다른 사람의 점수/순위와 미사용 능력 설명이 참가자에게 전송되지 않습니다. 사용된 능력은 상세 효과와 함께 공개됩니다.

## 인터넷 배포 (Render)

1. 이 프로젝트를 GitHub 저장소에 업로드합니다.
2. Render에서 **New → Blueprint**를 선택하고 저장소를 연결합니다. `render.yaml`이 웹서버 및 영구 저장 디스크를 정의합니다.
3. 환경변수 `ADMIN_PIN`에 관리자 비밀번호를 지정합니다. 사용자 요청대로 `0311`을 쓰려면 그렇게 설정할 수 있지만, 외부 공개 시 더 긴 PIN을 강력히 권장합니다.
4. 배포된 HTTPS 주소를 10명에게 공유하세요. Render 유료 디스크 플랜이 필요할 수 있습니다. **영구 디스크를 제거하면 재배포 때 DB 데이터가 사라질 수 있습니다.**

DB는 `DATA_DIR/workshop.db` SQLite 파일입니다. `data/`는 배포 소스에 포함하지 않습니다. 개인정보/점수를 보관하는 실제 운영에는 HTTPS, 비밀 PIN, 백업이 필요합니다.

## 비고

- 참가자 로그인 코드는 관리자가 참가자에게 각각 전달합니다.
- 점수 보정 및 게임 결과는 관리자 화면에서 처리합니다.
- 초능력/럭키 추첨은 서버에서 무작위로 확정되며 모바일은 결과를 조회합니다.
- 관리자 비밀번호는 서버에서만 검사합니다. 브라우저에 저장하지 않습니다.
- 본 프로젝트는 Node.js + 기본 SQLite 기반으로 동작하며 외부 API 키가 필요하지 않습니다.
